# TY Creatives

This is the portfolio site for TY Creatives, my flier design business. It's a single-page site — hero section up top, a bit about me, a grid showing off some of the flier designs I've done, and a contact section so people can reach out on email or WhatsApp.

Kept the design simple: black and gold, poster-style, nothing too busy. The whole point is to let the flier designs do the talking.

## What's in here
- Hero section with a quick intro
- About section
- Portfolio grid pulling images from the `IMAGES` folder
- Contact links (email + WhatsApp)

## Built with
Just plain HTML and CSS — no frameworks, no build tools. Fonts are pulled in from Google Fonts (Playfair Display + Work Sans).

## Running it
No setup needed, just open `index.html` in a browser. Since it's a static page, it can also be hosted straight from GitHub Pages.
